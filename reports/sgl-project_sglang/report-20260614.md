# AI Analysis of Pull Requests for sgl-project/sglang during 20260607-20260614

**Key Takeaways:** This week focused on aggressive kernel-level fusion for Diffusion (DiT) models and next-generation Blackwell (SM120) hardware, alongside a comprehensive architectural cleanup of legacy speculative decoding (EAGLE v1) in favor of Spec-V2, totaling 625 PRs across ① Diffusion DiT optimization, ② Speculative Decoding V2 maturation, ③ DeepSeek-V4/V3 architectural hardening, and ④ Multi-backend (AMD/Intel/NPU) parity.

1. **Diffusion Model Optimizations (DiT)**
    * Fused `GELU` into `proj_in` and `up-proj` GEMMs using `cublasLt` epilogues (`torch._addmm_activation`) for FLUX, LTX-2, and Qwen-Image to eliminate HBM round-trips [PR#28168](https://github.com/sgl-project/sglang/pull/28168), [PR#28167](https://github.com/sgl-project/sglang/pull/28167), [PR#28164](https://github.com/sgl-project/sglang/pull/28164).
    * Optimized Triton `_rotary_embedding_kernel` by replacing stride-2 gathers with contiguous loads and register-level deinterleaving, improving bandwidth utilization by 45-82% [PR#28147](https://github.com/sgl-project/sglang/pull/28147).
    * Introduced a multi-row path for `norm_infer` kernels to hide memory latency on small-N huge-M shapes (e.g., HunyuanVideo), achieving up to 5.75x speedup [PR#28146](https://github.com/sgl-project/sglang/pull/28146).
    * Enabled `channels_last_3d` for Cosmos3 VAE and added opt-in RMSNorm+SiLU fusion for Wan VAE [PR#28021](https://github.com/sgl-project/sglang/pull/28021), [PR#28014](https://github.com/sgl-project/sglang/pull/28014).

2. **Speculative Decoding & Spec-V2**
    * Deprecated and removed legacy EAGLE v1 code paths and `DRAFT_EXTEND` forward modes in favor of Spec-V2 [PR#28133](https://github.com/sgl-project/sglang/pull/28133), [PR#28129](https://github.com/sgl-project/sglang/pull/28129), [PR#27964](https://github.com/sgl-project/sglang/pull/27964).
    * Refactored `EagleDraftWorker` and `EagleVerifyInput` to move logic from dataclass mixins to worker-level free functions, improving separation of concerns [PR#28117](https://github.com/sgl-project/sglang/pull/28117), [PR#28105](https://github.com/sgl-project/sglang/pull/28105).
    * Fixed a critical CUDA synchronization bottleneck in Spec-V2 by allowing the CPU to launch the next stage (Draft i+1) before the current stage (Verify i) finishes, reducing GPU idle time [PR#27979](https://github.com/sgl-project/sglang/pull/27979).
    * Added `SuffixDecoding` as a model-free speculative algorithm using a CPU-side suffix tree to propose draft tokens [PR#27582](https://github.com/sgl-project/sglang/pull/27582).

3. **Hardware Backends & Blackwell (SM120) Support**
    * **Blackwell (SM120/121):** Added expert-grouped GEMM for `MXFP4` MoE prefill [PR#28155](https://github.com/sgl-project/sglang/pull/28155) and fixed `int8_scaled_mm` and `fp8_blockwise_scaled_grouped_mm` dispatch for consumer Blackwell parts [PR#28137](https://github.com/sgl-project/sglang/pull/28137), [PR#28125](https://github.com/sgl-project/sglang/pull/28125).
    * **AMD (ROCm):** Implemented GQA-grouped split-K verify kernels for EAGLE3/MTP, achieving 6x reduction in HBM traffic on gfx950 [PR#28124](https://github.com/sgl-project/sglang/pull/28124). Added `liteattention_rocm` backend for DiT models [PR#28049](https://github.com/sgl-project/sglang/pull/28049).
    * **Intel (XPU/CPU):** Extended `XPU` support for DeepSeek-V4 including `Hadamard` transforms and `fused_k_norm_rope` implementations [PR#28046](https://github.com/sgl-project/sglang/pull/28046), [PR#28040](https://github.com/sgl-project/sglang/pull/28040). Enabled speculative decoding on CPU (EAGLE2/MTP) [PR#27862](https://github.com/sgl-project/sglang/pull/27862).
    * **NPU:** Added end-to-end support for DeepSeek-V4-Flash architecture on Ascend NPU [PR#27904](https://github.com/sgl-project/sglang/pull/27904).

4. **DeepSeek-V4 & V3 Optimizations**
    * Introduced a `SharedMLA` hierarchical cache to store a single copy of compressed KV cache across TP ranks, reducing host DRAM usage by the TP factor [PR#28027](https://github.com/sgl-project/sglang/pull/28027).
    * Fused `Add` + `RMSNorm` + `per-token FP8 quantization` into a single JIT kernel for DeepSeek MoE backends [PR#28101](https://github.com/sgl-project/sglang/pull/28101).
    * Optimized `NSA` prefill context parallel (CP) by slicing repeated attention weights to local TP partitions, eliminating redundant computation [PR#27657](https://github.com/sgl-project/sglang/pull/27657).

5. **Framework Architecture & Performance**

    * **Scheduling:** Introduced `PrefillDelayer` to generalize DFlash refill heuristics into a wall-clock-bounded trigger [PR#28104](https://github.com/sgl-project/sglang/pull/28104).
    * **Networking:** Fixed ZMQ stale socket reconnection issues in PD disaggregation deployments [PR#27796](https://github.com/sgl-project/sglang/pull/27796).
    * **Observability:** Unified NVTX annotation helpers and split enable gates per subsystem (Scheduler vs. Operations) [PR#28165](https://github.com/sgl-project/sglang/pull/28165).
