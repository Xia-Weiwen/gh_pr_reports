### 2. Speculative Decoding (SD)
*   **Adaptive Speculation:** Introduced an `AdaptiveController` using EMA (Exponential Moving Average) to dynamically adjust `speculative_num_steps` based on acceptance rates, with per-batch-size independent state ([PR#24209](https://github.com/sgl-project/sglang/pull/24209), [PR#23994](https://github.com/sgl-project/sglang/pull/23994)).
*   **EAGLE/MTP Expansion:** Added support for Gemma 4 + EAGLE3 with auxiliary layer embedding captures ([PR#23976](https://github.com/sgl-project/sglang/pull/23976)) and fixed stop-string detection misses during multi-token speculative acceptance ([PR#23802](https://github.com/sgl-project/sglang/pull/23802)).
*   **Naming & Logic Refactor:** Standardized terminology to distinguish between `correct_drafts` (drafts only) and `accepted_tokens` (drafts + bonus) to reduce semantic ambiguity in metrics ([PR#24081](https://github.com/sgl-project/sglang/pull/24081), [PR#23962](https://github.com/sgl-project/sglang/pull/23962)).
*   **Infrastructure:** Established a registry for custom speculative algorithms, allowing downstream developers to plug in novel SD methods without core source modification ([PR#23991](https://github.com/sgl-project/sglang/pull/23991)).
