# AI Analysis of Pull Requests for sgl-project/sglang during 20260315-20260322

**Key Takeaways:** This week’s development of 405 PRs was dominated by stabilizing Blackwell (SM100/SM120) performance through kernel fusions and NVFP4/FP8 optimizations, alongside a massive push for feature parity on (1) Ascend NPU, (2) AMD ROCm, and (3) specialized Diffusion pipelines.

### 1. Performance & Kernel Engineering
*   **FlashAttention Optimizations:**
    *   [PR#21104](https://github.com/sgl-project/sglang/pull/21104) and [PR#21103](https://github.com/sgl-project/sglang/pull/21103) precompute `scheduler_metadata` for FA3, eliminating 63 redundant `prepare_varlen_num_blocks` kernel calls per decode step.
    *   [PR#21080](https://github.com/sgl-project/sglang/pull/21080) enables FlashAttention-4 (FP4) support within speculative decoding pipelines.
*   **Blackwell (SM100/SM120) Stability:**
    *   [PR#21109](https://github.com/sgl-project/sglang/pull/21109) fixes FlashInfer GDN decode padding issues and dispatcher routing on SM100.
    *   [PR#20887](https://github.com/sgl-project/sglang/pull/20887) improves FP8 Blockwise GEMM performance on SM120 by adopting a ping-pong scheduler.
*   **JIT Kernel Expansion:**
    *   [PR#20999](https://github.com/sgl-project/sglang/pull/20999) and [PR#20976](https://github.com/sgl-project/sglang/pull/20976) replace `torch.compile` paths with specialized CUDA JIT kernels for `clamp_position` and `resolve_future_token_ids` to reduce overhead.
    *   [PR#20661](https://github.com/sgl-project/sglang/pull/20661) extends JIT `RMSNorm` support for smaller hidden sizes ({64, 128, 256}).
*   **Triton Fusions:**
    *   [PR#21019](https://github.com/sgl-project/sglang/pull/21019) fuses split/reshape/cat operations in Qwen3.5 GDN projections using Triton.
    *   [PR#20778](https://github.com/sgl-project/sglang/pull/20778) introduces a fused Triton kernel for `normal_decode_set_metadata`.

### 2. Diffusion Pipeline Enhancements
*   **Dynamic Resolution & Batching:**
    *   [PR#21056](https://github.com/sgl-project/sglang/pull/21056) and [PR#21055](https://github.com/sgl-project/sglang/pull/21055) add latent H/W shape bucketing and mixed-resolution benchmarking to reduce runtime jitter in variable-resolution serving.
    *   [PR#21042](https://github.com/sgl-project/sglang/pull/21042) fixes Z-Image sequence-parallel (SP) sharding for portrait and padded resolutions.
*   **Model-Specific Optimizations:**
    *   [PR#21014](https://github.com/sgl-project/sglang/pull/21014) replaces `Conv3d` with `reshape` + `F.linear` in `PatchEmbed` for significant speedups in 5D video inputs.
    *   [PR#20879](https://github.com/sgl-project/sglang/pull/20879) implements KV caching for FLUX.2-klein-9b reference image conditioning.
*   **Cross-Platform Parity:**
    *   [PR#20816](https://github.com/sgl-project/sglang/pull/20816) initializes native CPU support for Diffusion (Intel Xeon) with shared-memory TP optimizations.
    *   [PR#20671](https://github.com/sgl-project/sglang/pull/20671) adds MUSA (Moore Threads) PR tests for Diffusion.

### 4. Architecture & Disaggregated Serving (PD)
