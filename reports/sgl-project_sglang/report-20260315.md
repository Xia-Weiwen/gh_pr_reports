# AI Analysis of Pull Requests for sgl-project/sglang during 20260308-20260315

**Key Takeaways:** This week’s activity centered on stabilizing production-grade performance for DeepSeek-V3 and Qwen3.5 architectures through specialized fused kernels and expanding multi-backend parity across AMD ROCm, Huawei Ascend NPU, and Apple MLX (392 total PRs), specifically targeting (1) hardware-specific kernel optimizations, (2) Speculative Decoding V2 (overlap scheduling), and (3) deep refactoring of the `RadixTree` and `HiCache` memory tiers.

1. **New Models and Architectures**
    * Support for the `GPT-NeoX` series (Pythia family) with verified MMLU and performance benchmarks [PR#20595](https://github.com/sgl-project/sglang/pull/20595).
    * Integration of `Jamba` (hybrid Mamba1 + Attention) and `Mamba1AttnBackend` for mixed batch prefill/decode [PR#20141](https://github.com/sgl-project/sglang/pull/20141).
    * Support for `Nemotron-3-Super-120B` including NVFP4 quantization variants via `modelopt_mixed` [PR#20407](https://github.com/sgl-project/sglang/pull/20407).
    * Integration of `Engram`, a conditional memory mechanism using n-gram hash-based embedding lookups for Qwen2/3 [PR#20231](https://github.com/sgl-project/sglang/pull/20231).

2. **Performance and Specialized Kernels**
    * **Fused Kernels:** Introduced `fused_share_gate_sigmoid_mul` for Qwen3.5, yielding 1-2% throughput gains under production SLA [PR#20589](https://github.com/sgl-project/sglang/pull/20589).
    * **Quantization:** Support for online weight quantization (`bf16` to `nvfp4`) during loading for Blackwell GPUs [PR#20549](https://github.com/sgl-project/sglang/pull/20549).
    * **Attention Optimizations:**
        * Integrated `POD-Attention` to fuse prefill and decode attention into a single kernel for `Mixed Chunk Prefill` mode [PR#20346](https://github.com/sgl-project/sglang/pull/20346).
        * Triton support for MLA with `FP8` KV cache, optimized for SM120 [PR#20479](https://github.com/sgl-project/sglang/pull/20479).
        * Fused `temperature + softmax` in the sampling path to reduce kernel launch overhead and memory passes [PR#20801](https://github.com/sgl-project/sglang/pull/20801).

Fixed `NSA` context parallelism producing garbage output on MI300X [PR#20359](https://github.com/sgl-project/sglang/pull/20359).
    * **NPU Ascend:** Implemented INT8 communication compression for TP groups [PR#20520](https://github.com/sgl-project/sglang/pull/20520) and introduced `HiSparse` to offload idle KV cache to CPU memory for NSA mechanisms [PR#20343](https://github.com/sgl-project/sglang/pull/20343).
    * **Apple MLX:** Added native `MlxModelRunner` and `MlxAttnBackend` for end-to-end inference on Apple Silicon [PR#20342](https://github.com/sgl-project/sglang/pull/20342), [PR#20221](https://github.com/sgl-project/sglang/pull/20221).
    * **Intel:** Unified XPU support for Qwen3 (Layernorm/MRoPE) and expanded `torchcodec` media decoding [PR#20473](https://github.com/sgl-project/sglang/pull/20473), [PR#20190](https://github.com/sgl-project/sglang/pull/20190).
