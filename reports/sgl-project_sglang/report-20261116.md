# AI Analysis of Pull Requests for sgl-project/sglang during 20261109-20261116

### Key Takeaways
This week's development is defined by a massive push for Day-0 performance parity for DeepSeek-V4.1 and Kimi-K3.1 across heterogeneous hardware, characterized by 1300 PRs focusing on (1) speculative decoding (DFlash/DSpark/MTP) and kernel fusion, (2) the architectural transition to a Unified Radix Cache memory pool, (3) hardware-specific acceleration for AMD MI355X and Ascend NPU, and (4) the near-completion of the Rust-based control-plane migration.

---

### 1. Speculative Decoding & MTP Optimizations
*   **DFlash & DSpark:** Integrated confidence-scheduled compact verification for DFlash2 on Kimi-K3.1 [PR#50587](https://github.com/sgl-project/sglang/pull/50587). Added support for pipeline-parallel (PP) disaggregated prefill for Muse Spark [PR#50232](https://github.com/sgl-project/sglang/pull/50232).
*   **Kernel Fusion:** Fused draft softmax and sampling for EAGLE rejection sampling [PR#50620](https://github.com/sgl-project/sglang/pull/50620). Fused penalties, logit bias, and temperature softmax in verify sampling to reduce eager launch overhead [PR#50061](https://github.com/sgl-project/sglang/pull/50061).
*   **Verification:** Implemented tree verification for GDN layers without per-node state snapshots [PR#50601](https://github.com/sgl-project/sglang/pull/50601). Support for DMTP (Dual-anchor MTP) speculative decoding [PR#50270](https://github.com/sgl-project/sglang/pull/50270).

### 2. Core Runtime & Memory Management
*   **Unified Memory Pool:** Transitioned toward a unified byte arena for KV and recurrent state, allowing same-lifetime parts to compose into a single sub-pool [PR#49966](https://github.com/sgl-project/sglang/pull/49966). Replaced largest-fit searches with demand-based capacity queries [PR#49300](https://github.com/sgl-project/sglang/pull/49300).
*   **Radix Cache & HiCache:** Support for `page_unified` storage for DeepSeek-V4/V4.1 and DSA pools, decoupling object identity from TP/PP topology [PR#50111](https://github.com/sgl-project/sglang/pull/50111).
*   **HiSparse:** Implemented an elastic device pool and per-request residency in HBM for long contexts to reduce host swap-in frequency [PR#50046](https://github.com/sgl-project/sglang/pull/50046).
*   **External Store:** Enhanced Mooncake L3 support for logical-page KV sharding [PR#50650](https://github.com/sgl-project/sglang/pull/50650).

### 3. Hardware-Specific Enablement
*   **AMD (ROCm):** Added `gfx1250` (MI450) support for Muse Spark [PR#50707](https://github.com/sgl-project/sglang/pull/50707). Integrated uTLX attention backend to leverage AMD's Tensor Data Mover (TDM) [PR#50415](https://github.com/sgl-project/sglang/pull/50415).
*   **NPU (Ascend):** Introduced breakable prefill graphs for DeepSeek-V4 [PR#49481](https://github.com/sgl-project/sglang/pull/49481). Support for block-FP8 MLA weights on Ascend 950 [PR#50670](https://github.com/sgl-project/sglang/pull/50670).
*   **Intel (XPU):** Enabled UNO support on XPU [PR#50359](https://github.com/sgl-project/sglang/pull/50359) and native kernels for DeepSeek-V4.1 Full Top-k/Candidate indexing [PR#49989](https://github.com/sgl-project/sglang/pull/49989).
*   **T-HEAD SAIL (PPU):** Comprehensive enablement for DeepSeek-V4.1, including PPU-specific DeepGEMM expert-parallel (EP) MoE runners [PR#50090](https://github.com/sgl-project/sglang/pull/50090) and MXFP4 downcast kernels [PR#50086](https://github.com/sgl-project/sglang/pull/50086).
*   **Apple Silicon:** Metal-native `SiLU` and multiply kernels for the Torch MPS path [PR#50160](https://github.com/sgl-project/sglang/pull/50160).

### 4. Multi-modal & Diffusion
