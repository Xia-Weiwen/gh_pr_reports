# AI Analysis of Pull Requests for sgl-project/sglang during 20260301-20260308

**Key Takeaways:** Aggressive feature expansion in the `SGLang-D` diffusion engine and `Eagle3` speculative decoding, coupled with deep-stack optimizations for Blackwell (SM120) hardware and a massive shift towards JIT-compiled kernels, defines this week's 416 PRs across (1) Diffusion backend maturity, (2) Eagle3 speculative decoding, (3) Blackwell and ROCm enablement, and (4) Kernel-level JIT migration.

### 1. Core Engine & Architecture
*   **Radix Cache Enhancements**: 
    *   Added a `CLOCK` second-chance eviction policy to reduce the $O(N \log N)$ cost of heap-based eviction in high-throughput scenarios to $O(1)$ [PR#20125](https://github.com/sgl-project/sglang/pull/20125).
    *   Implemented semantic-aware KV cache pruning to handle non-linear conversation patterns and agentic summarization workflows [PR#20088](https://github.com/sgl-project/sglang/pull/20088).
    *   Introduced `ExtendedRadixCache` and `BaseKVConnector` to support external KV cache offloading backends [PR#20007](https://github.com/sgl-project/sglang/pull/20007).
*   **Scheduling & Metrics**:
    *   Refactored priority scheduling to limit valid priority ranges and added `X-Sglang-Request-Priority` header support for PD disaggregation [PR#20129](https://github.com/sgl-project/sglang/pull/20129), [PR#19808](https://github.com/sgl-project/sglang/pull/19808).
    *   Added `GapTimer` to measure "overlap bubbles" (GPU idle time waiting for CPU scheduling) [PR#19822](https://github.com/sgl-project/sglang/pull/19822).
*   **CUDA Graph Optimizations**: 
    *   Significant fixes for Piecewise CUDA Graphs (`PCG`) including support for `Marlin` linear operators and disabling for XPU/XPU CI to prevent hangs [PR#20119](https://github.com/sgl-project/sglang/pull/20119), [PR#20124](https://github.com/sgl-project/sglang/pull/20124).

### 2. Speculative Decoding (Eagle3 & SpecV2)
*   **Eagle3 Expansion**: Added support for `Eagle3` on `Qwen3.5` and `Kimi-K2.5`, including a new multi-expert draft model support with per-request profile routing [PR#20104](https://github.com/sgl-project/sglang/pull/20104), [PR#19689](https://github.com/sgl-project/sglang/pull/19689), [PR#20000](https://github.com/sgl-project/sglang/pull/20000).
*   **Logprob Support**: Implemented logprob computation for `SpecV2` by following the forward/scheduler split, unblocking RL workloads using speculative decoding [PR#19801](https://github.com/sgl-project/sglang/pull/19801), [PR#19779](https://github.com/sgl-project/sglang/pull/19779).
*   **Stability**: Refactored `NaN` and Out-of-Bounds (`OOB`) detection to use `torch._assert_async`. This prevents CPU-GPU synchronization stalls, preserving the two-stream overlap performance in `Eagle` workers [PR#19899](https://github.com/sgl-project/sglang/pull/19899).

### 3. Diffusion Engine (SGLang-D)
*   **Performance**: Introduced fused CUDA kernels for `Residual + Norm + Modulation` in `Flux` and `Z-Image-Turbo`, significantly reducing kernel launch overhead in the DiT denoising loop [PR#19632](https://github.com/sgl-project/sglang/pull/19632).
*   **Quantization & Loading**: Added `fp8` (`float8_e4m3fn`) support for `TextEncoderLoader` and `ImageEncoderLoader` to handle pre-quantized checkpoints [PR#20121](https://github.com/sgl-project/sglang/pull/20121).
*   **Architecture**: Refactored the runtime into an explicit `GenerationService` facade to stabilize the boundary between protocol adapters and orchestration [PR#19838](https://github.com/sgl-project/sglang/pull/19838).

### 4. Hardware Backend & Model Support
*   **Blackwell (SM120)**: 
    *   Defaulted the `fp4-gemm-backend` to `flashinfer_cudnn` on Blackwell to avoid `NaN` issues observed with the `cutlass` backend during heterogeneous batching [PR#20047](https://github.com/sgl-project/sglang/pull/20047).
    *   Fixed `triton_kernels` MXFP4 tile selection to stay within SM120 shared memory limits [PR#20040](https://github.com/sgl-project/sglang/pull/20040).
*   **AMD/ROCm**: 
    *   Enabled FP8 KV cache support for the `Tilelang` NSA backend on AMD GPUs [PR#19990](https://github.com/sgl-project/sglang/pull/19990).
    *   Supported true on-policy RL via deterministic Triton attention backends to ensure bit-wise identical log-probs between rollout and training [PR#20111](https://github.com/sgl-project/sglang/pull/20111).
*   **NPU (Ascend)**: Optimized `W8A8` MoE decode by integrating `npu_moe_token_unpermute` and fused `dequant_swiglu_quant` operators [PR#19913](https://github.com/sgl-project/sglang/pull/19913).
*   **Model-Specific Fixes**: 
    *   Resolved `tie_word_embeddings` logic for `Qwen MoE` and `Qwen3Next` where `lm_head` weights were staying randomly initialized [PR#20127](https://github.com/sgl-project/sglang/pull/20127).
    *   Added UVM-based MoE expert offloading for `GLM-5-FP8` to allow 256-expert models to run on single-host 8xH20 setups [PR#20126](https://github.com/sgl-project/sglang/pull/20126).

### 5. Kernel JIT Migration
*   **AOT to JIT**: Continued the migration of the `sgl-kernel` library to `jit_kernel` to simplify deployment and improve version compatibility. Ported kernels include:
    *   `fast_topk` [PR#19958](https://github.com/sgl-project/sglang/pull/19958)
    *   `moe_align_block_size` [PR#19704](https://github.com/sgl-project/sglang/pull/19704)
    *   `moe_sum_reduce` [PR#19701](https://github.com/sgl-project/sglang/pull/19701)
    *   `per_token_quant_fp8` [PR#19702](https://github.com/sgl-project/sglang/pull/19702)
*   **Custom All-Reduce**: Implemented a JIT-compiled custom all-reduce (v2) incorporating Hopper-specific features like `PDL` (Payload Data Load) for a 20% latency reduction in small batch sizes [PR#19880](https://github.com/sgl-project/sglang/pull/19880).

### 6. Disaggregated Serving & Infrastructure
*   **P/D Disaggregation**: 
    *   Enabled `RadixCache` on decode workers to allow delta-only KV transfers, gated by `SGLANG_ENABLE_DECODE_RADIX_CACHE` [PR#19746](https://github.com/sgl-project/sglang/pull/19746).
    *   Developed a GPU staging buffer with a dynamic ring allocator for heterogeneous TP KV transfers (e.g., TP4 prefill to DEP4 decode) [PR#19890](https://github.com/sgl-project/sglang/pull/19890).
*   **Model Gateway**: Added `SubscribeKvEvents` gRPC streaming to allow external cache-aware routers to monitor `RadixCache` state in real-time [PR#20112](https://github.com/sgl-project/sglang/pull/20112).
