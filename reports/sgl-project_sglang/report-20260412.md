# AI Analysis of Pull Requests for sgl-project/sglang during 20260405-20260412

**Key Takeaway:** This week's development is dominated by the rapid stabilization and performance tuning of DeepSeek-V3/R1 and GLM-5 (DSA) architectures across 414 PRs, with primary focus on (1) hardware-specific kernel optimization for NPU/AMD, (2) advanced memory pool management for hybrid SSM-Attention models, and (3) maturing the Encoder-Prefill-Decode (EPD) disaggregation pipeline.

### 1. Model Architectures & DSA (Deep Sequential Attention)
* **GLM-5 & DeepSeek-V3/R1 Support:** Extensive integration for `GlmMoeDsaForCausalLM`, including nightly accuracy benchmarks and performance tuning [PR#22336](https://github.com/sgl-project/sglang/pull/22336). Multi-token prediction (MTP) and speculative decoding variants were expanded for these architectures [PR#22399](https://github.com/sgl-project/sglang/pull/22399), [PR#22222](https://github.com/sgl-project/sglang/pull/22222).
* **Gemma 4 & Qwen 3 Development:** Initial support for Gemma 4 on Xeon [PR#22498](https://github.com/sgl-project/sglang/pull/22498) and sliding window attention (SWA) for Qwen 3 models [PR#22529](https://github.com/sgl-project/sglang/pull/22529).
* **Multimodal Integration:** Support added for EXAONE-4.5 [PR#22456](https://github.com/sgl-project/sglang/pull/22456) and Kimi-VL [PR#22442](https://github.com/sgl-project/sglang/pull/22442). Implemented SVD-based low-rank KV cache compression (`AttentionPack`) for VLM inference to reduce visual token overhead by up to 8x [PR#22364](https://github.com/sgl-project/sglang/pull/22364).

### 2. Runtime Performance & Kernel Engineering
* **O(n²) Bottleneck Elimination:** Replaced quadratic string concatenations in `stream_buffer` with integer offsets [PR#22606](https://github.com/sgl-project/sglang/pull/22606) and eliminated linear copies in the non-incremental streaming tokenizer path [PR#22567](https://github.com/sgl-project/sglang/pull/22567).
* **CUDA Graph Evolution:** Added "Breakable Piecewise CUDA Graphs" that do not rely on the `torch.compile` backend [PR#22218](https://github.com/sgl-project/sglang/pull/22218). Fixed illegal memory access issues in Piecewise CUDA Graphs (PCG) by clamping `piecewise_cuda_graph_max_tokens` to the context window [PR#22516](https://github.com/sgl-project/sglang/pull/22516).
* **Communication & Fusion:** Optimized `custom_allreduce` to coexist with NCCL symmetric memory [PR#22354](https://github.com/sgl-project/sglang/pull/22354). Fused `QK-norm + RoPE` for Qwen 3 MoE on Hopper/Blackwell architectures [PR#22355](https://github.com/sgl-project/sglang/pull/22355).

### 3. Hardware Backends (NPU, AMD, Apple, RISC-V)
* **Ascend NPU:** Massive push for low-bit quantization, adding support for W8A8 `MXFP8` [PR#22352](https://github.com/sgl-project/sglang/pull/22352) and `MXFP4` [PR#22338](https://github.com/sgl-project/sglang/pull/22338). 
* **AMD ROCm:** Upgraded `aiter` to v0.1.12.post1 [PR#22264](https://github.com/sgl-project/sglang/pull/22264) and enabled DFLASH speculative decoding on ROCm via Triton fallback [PR#22342](https://github.com/sgl-project/sglang/pull/22342).
* **Apple Silicon (MLX):** Significant maturity for the MLX backend, including `PagedAttention` [PR#22198](https://github.com/sgl-project/sglang/pull/22198), GPU profiling via Metal capture API [PR#22519](https://github.com/sgl-project/sglang/pull/22519), and overlap scheduling for decode passes [PR#22415](https://github.com/sgl-project/sglang/pull/22415).
* **RISC-V (RVV):** Introduced hand-written RVV 1.0 intrinsics in `sgl-kernel` for GEMM, Norm, and Attention, targeting SpacemiT K1 hardware [PR#22193](https://github.com/sgl-project/sglang/pull/22193), [PR#22219](https://github.com/sgl-project/sglang/pull/22219).

### 4. Memory & Cache Management
* **Hybrid Pool Refactor:** Introduced `MemoryPoolConfigurator` hierarchy to manage complex interactions between KV, SWA, and Mamba pools [PR#22389](https://github.com/sgl-project/sglang/pull/22389). Flattened monolithic memory checkers into composable per-pool invariant checks [PR#22562](https://github.com/sgl-project/sglang/pull/22562).
* **HiCache & HiSparse:** Added `v2 hybrid-pool` support to `HiCacheHF3FS` for offloading both KV and Mamba states [PR#22601](https://github.com/sgl-project/sglang/pull/22601). Integrated `HiSparse` with speculative decoding by using extra page slots as a dedicated draft zone [PR#22411](https://github.com/sgl-project/sglang/pull/22411).
* **Mamba State Caching:** Replaced ping-pong dual buffering with direct radix slot allocation, achieving +37% throughput at high concurrency [PR#22542](https://github.com/sgl-project/sglang/pull/22542).

### 5. Serving Infrastructure & Disaggregation
* **EPD (Encoder-Prefill-Decode):** Optimized the Mooncake backend by removing CPU-staged paths for vision embeddings [PR#22587](https://github.com/sgl-project/sglang/pull/22587). Added staging buffer support for heterogeneous TP layouts during KV transfer [PR#22536](https://github.com/sgl-project/sglang/pull/22536).

* **Observability:** Introduced a `#pending-token` metric to the prefill log to better track load in long-context, chunked-prefill scenarios [PR#22480](https://github.com/sgl-project/sglang/pull/22480).
