# AI Analysis of Pull Requests for sgl-project/sglang during 20260322-20260329

**Key Takeaway:** This week's development is dominated by the aggressive expansion of hardware-specific optimizations for (1) NVIDIA Blackwell (SM100/SM120) and (2) Ascend NPU, alongside a strategic shift toward (3) unified plugin-based extensibility and (4) matured diffusion pipeline features, totaling over 415 PRs.

### 1. Core Architecture and Performance
* **Unified Plugin Framework:** Introduced a hardware-abstracted plugin system using `setuptools` entry points, allowing vendors to register custom device ops, KV cache pools, and attention backends without forking the core repo [PR#21388](https://github.com/sgl-project/sglang/pull/21388).
* **Radix Cache Evolution:**
    *   Launched `HybridRadixCache` V2, unifying `MambaRadixCache` and `SWARadixCache` into a pluggable tree structure to reduce code duplication [PR#21206](https://github.com/sgl-project/sglang/pull/21206).
    *   Added support for `IndexCache` for DeepSeek-V3.2 to optimize prefix matching [PR#21405](https://github.com/sgl-project/sglang/pull/21405).
* **Kernel Fusion & Optimization:**
    *   Fused `scaled_dot_kkt`, `solve_tril`, and `recompute_w_u` for the KDA prefill pipeline, reducing separate kernel dispatches and intermediate tensor allocations [PR#21604](https://github.com/sgl-project/sglang/pull/21604).
    *   Optimized `moe_align_block_size` to support >1024 experts (up to 4096) for large MoE configurations and LoRA experts [PR#21610](https://github.com/sgl-project/sglang/pull/21610).
    *   Integrated `FlashInfer` v0.6.7, including `mxfp8` GEMM support [PR#21613](https://github.com/sgl-project/sglang/pull/21613).

### 3. Diffusion and Multimodal

* **New Model Support:**
    *   Added support for Wan S2V [PR#21609](https://github.com/sgl-project/sglang/pull/21609).
    *   Integrated `InternVL-U`, supporting both multimodal text generation and DiT-based image decoding [PR#21355](https://github.com/sgl-project/sglang/pull/21355).
    *   Supported first-class overlay model materialization for non-diffusers diffusion models [PR#21600](https://github.com/sgl-project/sglang/pull/21600).
* **Runtime Optimizations:** Implemented persistent workspace reuse to reduce per-step allocation overhead in denoising loops [PR#21573](https://github.com/sgl-project/sglang/pull/21573).

### 4. Quantization and Speculative Decoding
* **TurboQuant:** Implemented Google’s data-oblivious KV cache compression (3-4 bit) for near-zero accuracy loss without calibration [PR#21419](https://github.com/sgl-project/sglang/pull/21419).
* **Adaptive Speculation:** Added dynamic `speculative_num_steps` adjustment for `EAGLE` (topk=1) based on per-batch acceptance length EMA [PR#21599](https://github.com/sgl-project/sglang/pull/21599).
* **FP4/MXFP8 Support:** Extended `FlashInfer` TRTLLM-Gen MoE kernels to support non-gated activations (e.g., Nemotron) and FP4/MXFP8 weight alignment [PR#21321](https://github.com/sgl-project/sglang/pull/21321).
