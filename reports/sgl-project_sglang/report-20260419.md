# AI Analysis of Pull Requests for sgl-project/sglang during 20260412-20260419

### Key Takeaways
This week's development is characterized by the aggressive expansion of the diffusion serving pipeline and deep architectural optimizations for heterogeneous hardware backends (AMD, NPU, MUSA) and speculative decoding variants across 459 PRs, focusing on (1) multi-stage diffusion pipelines, (2) hardware-specific kernel backends (AMD, NPU, MUSA), (3) speculative decoding performance (EAGLE3, DFlash, MTP), and (4) prefix/radix cache refactoring for streaming sessions.

*   **Speculative Variants:** 
    *   Enabled `DFlash` support for Speculative V2 on NPU [PR#23122](https://github.com/sgl-project/sglang/pull/23122) and B200 [PR#23000](https://github.com/sgl-project/sglang/pull/23000).
    *   Implemented `TLI` (Token-Level Intersection) for lossless speculative decoding across heterogeneous vocabularies [PR#22883](https://github.com/sgl-project/sglang/pull/22883).
    *   Added support for randomly-initialized `MTP` (Multi-Token Prediction) heads for Qwen3 draft models [PR#23147](https://github.com/sgl-project/sglang/pull/23147).
    *   Fixed `EAGLE3` hidden state capture during `CudaGraph` initialization to prevent target-side execution from using draft-side configurations [PR#22836](https://github.com/sgl-project/sglang/pull/22836), [PR#22781](https://github.com/sgl-project/sglang/pull/22781).
*   **Radix Cache and Session Management:**
    *   Integrated streaming-session support natively into `UnifiedRadixCache` via composition with `SessionAwareCache` [PR#23145](https://github.com/sgl-project/sglang/pull/23145).
    *   Modularized `RadixAttention` to allow routing between vanilla and custom implementations via `radix_cache_impl` [PR#23116](https://github.com/sgl-project/sglang/pull/23116).
    *   Optimized `RadixKey` construction by replacing `O(N)` tuple-list allocations with an `is_bigram` flag for `EAGLE` keys [PR#23106](https://github.com/sgl-project/sglang/pull/23106).
*   **Disaggregation (PD):**
    *   Resolved scheduler hangs in Pipeline Parallelism (PP) by fixing `_get_new_batch_prefill_raw` logic [PR#23006](https://github.com/sgl-project/sglang/pull/23006).
    *   Implemented logical clock-based deterministic `LRU` eviction across PP ranks to prevent host-tree divergence [PR#22759](https://github.com/sgl-project/sglang/pull/22759).
