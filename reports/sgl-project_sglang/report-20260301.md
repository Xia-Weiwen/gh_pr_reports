# AI Analysis of Pull Requests for sgl-project/sglang during 20260222-20260301

### Key Takeaways
This week's development is centered on achieving feature parity for AMD/ROCm hardware and a systemic migration of core kernels from AOT to JIT compilation to improve framework maintainability and Blackwell (SM100/120) readiness. 

Total PRs: 367. Top active areas: (1) AMD Instinct parity, (2) Kernel JIT migration, (3) Qwen3.5 and DeepSeek-V3.2 architecture optimizations, (4) Disaggregated (PD) execution scalability.

---

### 1. Hardware Backends & Architecture Support
*   **AMD/ROCm (MI300X/MI325X/MI35X):**
    *   Ported tree speculative sampling kernels to HIP for EAGLE/n-gram support on ROCm [PR#19591].
    *   Enabled MoRI-EP support for EP4 [PR#19578] and fixed MoRI EP warmup hangs [PR#19498].
    *   Optimized FP8 prefill via fused GEMM with FP8 cast [PR#19422].
    *   Added support for MXFP4 quantized dense models on CDNA2/CDNA3 via Petit emulation [PR#19143].
*   **Ascend NPU:**
    *   Introduced `mla_ag_after_qlora` for DeepSeek-V3.2 to reduce high-dimensional communication overhead by 85% [PR#19428].
    *   Optimized GLM-4.7 performance via dual-stream DeepEP and fused `split_qkv_rmsnorm_rope` operators [PR#19246].
    *   Extended test coverage for VLM and embedding models (BGE, CLIP, Qwen3) [PR#19426].
*   **Framework Portability:**
    *   **MLX:** Implemented `MLXGraphRunner` for DECODE-only inference on Apple Silicon [PR#19261].
    *   **CPU:** Optimized Qwen3.5 performance and added `fused_sigmoid_gating_delta_rule_update` support [PR#19484].

### 2. Kernel Engineering & JIT Migration
*   **Kernel Slimming Initiative:** Massive migration of AOT compiled kernels in `sgl-kernel` to `jit_kernel` to reduce binary bloat and enable runtime optimization:
    *   NVFP4 kernels (quant, scaled MM, blockwise MoE) [PR#19437], [PR#19301].
    *   Marlin and Marlin MoE kernels [PR#19241], [PR#19181].
    *   Custom AllReduce and `store_kv_cache` [PR#19297], [PR#19298].
*   **Blackwell Optimization:** Added `tinygemm2` for BF16 small GEMM optimized for SM100 router/GEMM workloads [PR#19542].
*   **FlashInfer Integration:** Support for v0.6.4, including MXFP8 GEMM and gated delta rule decode kernels for hybrid attention models [PR#19537], [PR#19150].
*   **Kernel Fusion:** Fused Qwen3-Next GDN's `qkvz_proj` and `ba_proj` [PR#19321] and integrated a fused `fused_rms_norm_gated` kernel [PR#19434].

### 3. Distributed & Disaggregated Execution (PD)
*   **KV Return:** Implemented reverse RDMA transfer from decode to prefill workers. This allows disaggregated workers to transfer generated KV cache back to the prefill's RadixCache for multi-turn hit efficiency [PR#19353].
*   **Async Pipeline Parallelism:** Refactored the PP mechanism into an "authentic" async mode using `isend_tensor_dict` and `tensor.record_stream()` to ensure communication/computation overlap [PR#19582].
*   **Reliability:** Added deterministic worker ordering in the registry to ensure multi-router Kubernetes deployments maintain a synchronized view of cluster topology [PR#19579].
*   **Mooncake/NIXL Enhancements:** Added `mooncake_to_scheduler` backend for large vision embedding transfers, reducing D2H/H2D overhead [PR#19575].

### 4. Model-Specific Optimizations & Quantization
*   **Qwen 3.5 Suite:**
    *   Added support for loading hybrid MoE (GatedDeltaNet) models from GGUF [PR#19585].
    *   Enabled Multi-Token Prediction (MTP) v2 and fixed GQA head pairing mismatches in FLA kernels [PR#19391], [PR#19584].
    *   Fixed repetitive output bugs in `Qwen3.5-27B` caused by incorrect MLP all-reduce fusion logic [PR#19411].
*   **DeepSeek V3/V3.2:**
    *   Implemented "waterfill" load balancing for shared expert dispatch in DeepEP, treating shared experts as a dynamic balancing lever [PR#19290].
    *   Optimized weight loading for large expert counts (256+) by replacing linear scans with O(1) matching [PR#19299].
*   **Embedding Support:** Added `perplexity-ai/pplx-embed-v1-0.6b` and corresponding benchmark scripts [PR#19526], [PR#19292].

### 5. Diffusion & Multimodal Gen
*   **New Architectures:** Support added for Wan 2.2 (frame interpolation using RIFE) [PR#19384], SANA (with Gemma2 text encoder) [PR#19234], and FlashTalk (talking-face video generation) [PR#19229].
*   **Performance:** Integrated CUDA graph support for Qwen-Image [PR#19516] and implemented coarse-grained memory offload/wake APIs to release GPU memory during idle [PR#19152].
*   **Parallelism:** Corrected Ulysses SP bugs in FLUX.2 for image editing and replicated text tokens [PR#19454].

### 6. Observability & System Core
*   **Tracing:** Added OpenTelemetry spans for speculative decoding phases (draft, verify, accept) [PR#19545] and KV cache eviction/load-back events [PR#19390].
*   **Metrics:** Introduced estimated Model Flops Utilization (MFU) counters (FLOPs, read/write bytes) into Prometheus for production performance tracking [PR#19395].
*   **Session Management:** Introduced `streaming` sessions with `SessionAwareCache`, bypassing radix matching on sequential turns for latency-sensitive applications [PR#19171].
*   **Memory Management:** Refactored CUDA graph input buffers into a shared pool to reuse allocations across different execution phases [PR#19180].
