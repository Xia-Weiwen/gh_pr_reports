# AI Analysis of Pull Requests for sgl-project/sglang during 20260329-20260405

### Key Takeaway
This week’s development is dominated by intensive hardware enablement for Blackwell (SM100) via `NVFP4` and `MXFP8` precision paths, alongside significant architectural hardening of the Prefill-Decode (PD) disaggregation logic across 413 PRs, focusing on (1) Blackwell/NVFP4 quantization, (2) Diffusion performance, (3) Speculative decoding (EAGLE/NEXTN), and (4) AMD/NPU hardware parity.

---

### 1. Hardware Backends & Acceleration

    *   Integrated `NVFP4` scaled-mm correctness tests and benchmarked against DeepGEMM [PR#22127](https://github.com/sgl-project/sglang/pull/22127), [PR#22091](https://github.com/sgl-project/sglang/pull/22091).
    *   Set TRTLLM kernels as default for Blackwell [PR#21914](https://github.com/sgl-project/sglang/pull/21914) and added `MXFP8` optimized kernels [PR#21881](https://github.com/sgl-project/sglang/pull/21881).
    *   Resolved TRTLLM attention hangs on (G)B300 (SM103) by gating selection to exact SM100 [PR#21906](https://github.com/sgl-project/sglang/pull/21906).
*   **AMD (ROCm):**
    *   Enabled `AITER` All-reduce + `RMSNorm` fusion and expanded `hidden_dim` support [PR#21986](https://github.com/sgl-project/sglang/pull/21986), [PR#21947](https://github.com/sgl-project/sglang/pull/21947).
    *   Introduced `FP4` (E2M1) KV cache quantization for NSA using the TileLang backend [PR#21889](https://github.com/sgl-project/sglang/pull/21889).
    *   Added support for consumer RDNA3 GPUs (gfx1100, gfx1103) [PR#21697](https://github.com/sgl-project/sglang/pull/21697).
*   **Ascend NPU:**
    *   Implemented `NEXTN` (MTP) speculative decoding support for DeepSeek-V3.2 [PR#21759](https://github.com/sgl-project/sglang/pull/21759).
    *   Added support for `Qwen3.5` long-context and accuracy fixes [PR#22027](https://github.com/sgl-project/sglang/pull/22027), [PR#21847](https://github.com/sgl-project/sglang/pull/21847).
*   **Multi-Platform:**
    *   Added Arm64 CPU CI bootstrap [PR#22123](https://github.com/sgl-project/sglang/pull/22123) and Apple MLX correctness/accuracy tests [PR#21770](https://github.com/sgl-project/sglang/pull/21770).

### 2. Quantization & KV Cache Kernels
*   **TurboQuant:** Introduced **TurboQuant** (ICLR 2026) support, achieving ~5x KV cache compression with <2% PPL degradation via randomized Hadamard transforms [PR#22048](https://github.com/sgl-project/sglang/pull/22048), [PR#21628](https://github.com/sgl-project/sglang/pull/21628).
*   **Fused JIT Kernels:**
    *   New fused kernel combining `Residual-Add` + `RMSNorm` + `per-token FP8 quantization` [PR#22005](https://github.com/sgl-project/sglang/pull/22005).
    *   Fused `RoPE` + `FP8` quantization + `KV store` to eliminate intermediate BF16 writes [PR#21871](https://github.com/sgl-project/sglang/pull/21871).
    *   Fused `SiLU` + `Mul` + `FP8` quantization for MoE throughput [PR#21870](https://github.com/sgl-project/sglang/pull/21870).
*   **KV Cache Management:** Added phase-1 `INT8` KV cache support for Triton MHA [PR#22004](https://github.com/sgl-project/sglang/pull/22004) and `MXFP4` support on MI355X [PR#21627](https://github.com/sgl-project/sglang/pull/21627).

### 3. Speculative Decoding & Graphs
*   **EAGLE & SpecV2:**
    *   Implemented "Zero Bubble" scheduling for `EAGLE3` to eliminate CPU-side dispatch bottlenecks [PR#21895](https://github.com/sgl-project/sglang/pull/21895).
    *   Added support for logit penalties (`frequency`, `presence`, `bias`) in the SpecV2 verify path [PR#22049](https://github.com/sgl-project/sglang/pull/22049).
    *   Fixed a race condition in `EAGLE v2` where `plan_stream` read tensors before `main_stream` writes completed [PR#22113](https://github.com/sgl-project/sglang/pull/22113).
*   **CUDA Graph Enhancements:**
    *   Allowed piecewise CUDA graphs (`PCG`) to coexist with `MTP` speculative decoding [PR#22128](https://github.com/sgl-project/sglang/pull/22128).
    *   Reworked `LoRA` backend for CUDA graph compatibility via pre-allocated buffers [PR#21647](https://github.com/sgl-project/sglang/pull/21647).

### 4. Multimodal & Diffusion
*   **Audio/Transcription:** Added chunk-based streaming ASR support for `Qwen3-ASR` [PR#22089](https://github.com/sgl-project/sglang/pull/22089), [PR#22073](https://github.com/sgl-project/sglang/pull/22073).
*   **Diffusion Pipelines:**
    *   Added support for `LTX-2.3` and associated Image-to-Video pipelines [PR#22111](https://github.com/sgl-project/sglang/pull/22111), [PR#22075](https://github.com/sgl-project/sglang/pull/22075).
    *   Introduced "Disaggregated Diffusion" to separate compute stages [PR#21701](https://github.com/sgl-project/sglang/pull/21701).
    *   Implemented `Z-Image-Turbo` full `FP8` quantization and CUDA Graph capture [PR#21912](https://github.com/sgl-project/sglang/pull/21912).
*   **VLM Optimization:** Enabled chunk-aware `ViT` encoding to reduce peak memory by only encoding images overlapping the current prefill chunk [PR#22038](https://github.com/sgl-project/sglang/pull/22038).
